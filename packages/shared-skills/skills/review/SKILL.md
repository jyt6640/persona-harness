# Review

Report findings first, ordered by impact and grounded in code or verification
evidence. Separate confirmed defects from residual test gaps. For a review-only
request, report findings without edits. When review is part of an already
authorized implementation or fix, address in-scope defects and recheck affected
behavior without asking for duplicate approval. Report any remaining blocker;
review prose does not grant workflow completion authority.
