# v0.8.19 Release Notes

## Historical package authority

`0.8.19` was published as an immutable stable release. Its root package,
lockfile, private shared-skills package, and
`consumer-authority-v0819-acceptance.json` remain historical release evidence;
they cannot authorize a later candidate or a second publish.

## Authority archive intake

Authority archive intake keeps full no-follow identity checks for the archive
and its direct parent. Retained ancestor directories are rechecked for the
same no-follow location and mode, so unrelated concurrent sibling entries do
not invalidate an unchanged archive. Any symlink, replacement, non-directory
ancestor, direct-parent change, malformed archive, or tuple mismatch remains
blocked before verifier or authority state.

## Release boundary

The release completed through protected integration, a stable GitHub Release,
and one npm `latest` publication. Fixture and V4 observations remain separate
evidence paths and do not alter this immutable release history.
