# v0.8.19 Release Notes

## Current package authority

`0.8.19` is the current unpublished package authority after immutable,
unpublished `0.8.18` history. The root package, lockfile, private
shared-skills package, and `consumer-authority-v0819-acceptance.json` bind the

authorize this candidate.

## Authority archive intake

Authority archive intake keeps full no-follow identity checks for the archive
and its direct parent. Retained ancestor directories are rechecked for the
same no-follow location and mode, so unrelated concurrent sibling entries do
not invalidate an unchanged archive. Any symlink, replacement, non-directory
ancestor, direct-parent change, malformed archive, or tuple mismatch remains
blocked before verifier or authority state.

## Release boundary

This branch prepares the `0.8.19` package authority only. Fresh Source and
Package gates must bind the exact candidate and canonical tar before protected
integration, stable Release, and a single latest publish. Fixture and V4
observations remain separately authorized steps.
