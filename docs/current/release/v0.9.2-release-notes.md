# v0.9.2 Release Notes

## Recognizable Portable Skills

Persona Harness adapters generated by `ph init` now use the portable
host-facing name `ph-<skill-id>`. Their description and visible heading begin
with `(PH)`, so users can identify Persona Harness guidance in Codex, Claude
Code, OpenCode, and Antigravity without putting punctuation into the machine
identifier.

The generated adapter paths remain unchanged. A later `ph init` can refresh an
unchanged Persona-owned adapter through the existing manifest ownership check;
customized, ambiguous, or symlinked adapters remain fail-closed and untouched.

## Boundaries Preserved

- This is a static skill-discovery change only. It does not claim that a live
  host session selected or followed a skill.
- It does not enable runtime injection, hooks, workflow state, network,
  evidence, authority, or automatic updates.
- Context delivery remains explicit and default-off.

## Verification

The release path verifies all three generated adapter layouts, their stable
paths and OpenCode duplicate-prevention metadata, TypeScript type safety, the
canonical packed package, protected CI, and registry provenance.
