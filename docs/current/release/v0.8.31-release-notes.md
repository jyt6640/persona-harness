# v0.8.31 Release Notes

## Clearer workflow Finish diagnostics

When `ph workflow finish implement` cannot reserve the source-read runtime, it
now reports `Blocker: source-read-runtime-unavailable` with a bounded next
action: restore the source-read environment before retrying Finish.

Implementation and review reports or workflow history archives may already be
present when this occurs. They remain diagnostic-only evidence and do not grant
Finish authority, justify a workflow retry, or certify generated application
quality.

## Release boundary

Fresh source and package verification bind the exact `0.8.31` tar before
protected integration, immutable tagging, the stable GitHub Release, and one
npm `latest` publication. Registry and provenance readback remain the separate
completion record for that publication.
