# v1.1.1 Release Notes

Version 1.1.1 preserves the actual cause when Persona Harness cannot read a
project tree. Unsafe paths, bounded read limits and unavailable native runtime
are reported separately; each continues to block completion when applicable.

Tag creation, GitHub release verification, npm publication and registry
readback remain separate release workflow evidence.

## Changes

- Keep `source-read-unsafe`, `source-read-limit` and
  `source-read-runtime-unavailable` distinct through boundary reservation,
  workflow closure, Finish and cooperative Gradle verification.
- Report the failure code in the CLI instead of claiming every read failure is
  a native runtime failure.
- Keep no-follow checks and the 20,000-entry, 64-MiB snapshot ceiling intact.

## Install

```bash
npm install -D persona-harness@latest
npx ph init
```

## Supported Scope

- Node.js CLI source-read diagnostics and fail-closed workflow gates.
- macOS and Linux native project-read artifacts supported by this package.

## Not Supported

- This release does not raise project snapshot limits or bypass symlink checks.
- It does not certify generated application quality or guarantee cooperative
  Finish can pass when a project exceeds a bounded read limit.
