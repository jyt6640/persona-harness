# v0.8.23 Release Notes

## Current package authority

`0.8.23` is the current unpublished package authority. The root package,
lockfile, private shared-skills package, and
`consumer-authority-v0823-acceptance.json` bind the same version. Published
`0.8.22` is immutable historical evidence and cannot authorize this candidate
or a replacement publish.

## Deterministic npm landing README

The package tarball contains exactly one root README candidate, `README.md`,
so npm's package landing page uses the current English first screen and
30-second demo. Korean, Japanese, and Simplified Chinese source documents
remain in `docs/current/`; the English README links to their GitHub source
paths. This changes presentation selection only and makes no claim about
translation quality.

## Release boundary

Fresh Source and Package gates must bind the exact `0.8.23` candidate and its
canonical tar before protected integration, stable Release, and one npm
`latest` publication. Registry readback must report `readmeFilename` as
`README.md` and retain the candidate's canonical tar identity.
