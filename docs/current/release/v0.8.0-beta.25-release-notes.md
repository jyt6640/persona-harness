## Explicit Tool And Cleanliness Rules

Every source-built, fresh-tar, supplied-bundle, and observer grammar-preflight
path receives one explicit `gh` executable input. It must be an absolute,
regular, non-symlink executable whose bounded direct `--version` result is
compatible with `>=2.96.0 <3.0.0`. The contract executes that path directly
with no shell or PATH lookup. A missing, alias, malformed, unavailable, or
unsupported executable is a bounded block; the package never downloads or
installs a tool, invokes an artifact, or introduces a credential fallback.
The required protected Linux Node20 package scripts pass the same fixed
`/usr/bin/gh` input; it is still lstat- and version-validated before parser
preflight.

The V4 final-observer procedure retains host-state isolation: all fifteen
external host-state roots stay outside the consumer realpath under `env -i` and
explicit tool requirements.
At baseline, source-bound preparation, credential handoff, observer child, and
immediately before push, it compares NUL-safe untracked and ignored Git status
with the stage-specific normalized `git clean -ndx` projection. Only the
reviewed runtime/build residues may exist. `.local`, `.config`, `.cache`, a
tracked modification, an unexpected residue, or an alias/replacement remains a
fail-closed block. Linux may add only `UV_USE_IO_URING=0` to the existing fixed
authority-fetch child environment; any other extra key or value remains
blocked.

The source-built and fresh packed-installed contracts use the same explicit
observer-gh validation, V4 evaluator, no-token grammar preflight, fixed child
diagnostics, package root binding, and no-source-fallback checks. They preserve
the public Java/Spring readiness route, privacy constraints, modeled
trusted/unconsumed authority, one Finish consumption, and replay block without
accessing a live artifact.

fixture commit and normal push. The already prepared same consumer must then
immediately acquire and verify current original bytes online before the leaf

replay rejection. It must not reset, reinitialize, switch consumers, change
CWD/HEAD/source/profile, or replace its isolated home/store after fetch.
