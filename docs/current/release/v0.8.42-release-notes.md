# v0.8.42 Release Notes

## Optional Init Support Link

`ph init` now shows a compact link to star Persona Harness after it commits an
owned initialization transaction. The prompt is optional and appears only when
the command made an actual managed change.

## Safety And Scope Boundaries

- The link is not shown for `--dry-run`, an unchanged no-op rerun, invalid
  usage, or a fail-closed initialization error.
- Persona Harness does not check whether a user starred the repository, call
  GitHub, authenticate, collect telemetry, or persist user state for this
  prompt.
- The initialization ownership, transaction, and fail-closed behavior remain
  unchanged.

## Verification

The release path verifies the focused init CLI contract, TypeScript type safety,
the repository fast suite, documentation and release-policy checks, an isolated
installed tarball, protected CI, canonical package identity, and registry
provenance.
