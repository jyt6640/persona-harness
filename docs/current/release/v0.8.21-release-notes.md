# v0.8.21 Release Notes

## Historical package authority

`0.8.21` was published as an immutable stable release. Its root package,
lockfile, private shared-skills package, and
`consumer-authority-v0821-acceptance.json` remain historical release evidence;
they cannot authorize a later candidate or a second publish.

## Portable repair source identity

`ph attach --repair --yes` uses backend instruction inference while it repairs
a recognized portable static baseline. The generated observation reports
`.persona/instructions/inferred.json` and
`.persona/instructions/conflicts.json` can include a temporary staging path and
generation time, so project-finish source identity excludes exactly those two
runtime files.

The exclusion is intentionally narrow. A reviewed
`.persona/instructions/adopted.json`, any manually authored instruction, and
all other tracked or untracked source stay in the signed identity and continue
to drift or fail closed as before.

## Historical boundary

The release completed through protected integration, a stable GitHub Release,
and one npm `latest` publication. Fixture and V4 observations remain separate
evidence paths and do not alter this immutable release history.
