# v0.8.24 Release Notes

## Current package authority

`0.8.24` is the current unpublished package authority. The root package,
lockfile, private shared-skills package, and
`consumer-authority-v0824-acceptance.json` bind the same version. Published
`0.8.23` is immutable historical evidence and cannot authorize this candidate
or a replacement publish.

## Exact cooperative Gradle/JUnit demo

Repository maintainers and reviewers can run
`node scripts/verify-cooperative-finish-demo.mjs` from a Node 20.19+, JDK 21, Gradle 9.4.0
checkout. The command packs and installs the candidate package into a
disposable Java/Spring fixture, demonstrates the initial
`workflow-state-uninitialized` block, records actual Gradle/JUnit evidence,
and then reaches `Finish status: PASS` with `--assurance cooperative`.

Required `Verify repository` runs that exact command. The legacy runtime-hook
demos use the named `PersonaHarnessPlugin` entrypoint with an explicit
test-local preview opt-in, while ordinary installs remain default-off.

This is a local cooperative workflow contract. It does not grant trusted
external authority or make a generated-application quality claim.

## Release boundary

Fresh Source and Package gates must bind the exact `0.8.24` candidate and its
canonical tar before protected integration, stable Release, and one npm
`latest` publication. A later fixture or V4 observation remains separately
governed.
