# v0.8.33 Release Notes

## Generic current package authority

Current package authority now uses a single declarative current acceptance
record and shared reader instead of creating another version-named acceptance
schema. The record binds the root package, lockfile, and private shared-skills
package to the same release version while preserving the prior `0.8.32`
package record as strict, non-reusable history. The record separately names
the latest published release it may use only as immutable historical context.

Installed package preflights, canonical package checks, and release workflow
policy now read that current record. They retain the same fail-closed package,
attestation, and observer boundaries; this change does not invoke external
authority, fetch artifacts, consume Finish authority, or claim a Context host
observation.

## Release boundary

Fresh source and package verification bind the exact `0.8.33` tar before
protected integration, immutable tagging, the stable GitHub Release, and one
npm `latest` publication. Registry and provenance readback remain the separate
completion record for that publication.
