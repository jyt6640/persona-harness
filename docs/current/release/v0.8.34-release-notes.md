# v0.8.34 Release Notes

## Deterministic Context Comparison

This release adds a repository-side three-arm Context comparison protocol. It
evaluates the fixed ten-fixture corpus across Context OFF, legacy broad
compatibility, and targeted layered envelopes through a single versioned result
schema.

Run it from a source checkout with an explicit full Git commit and package
version:

```bash
npm run benchmark:context -- \
  --candidate-commit <full-current-commit> \
  --package-version <exact-package-version>
```

The runner rejects a checkout identity mismatch before it evaluates the corpus.
Successful local output contains thirty deterministic records with rule
identifiers, layers, and digests only.

## Safety And Claim Boundaries

- The comparison runner is repository tooling, not an installed user command.
- It does not invoke a model, host adapter, network, workflow, authority, or
  evidence path.
- Host, model, and operational measurements remain unavailable in local output.
- Every local product verdict remains `INCONCLUSIVE`; the protocol does not
  establish host delivery, user benefit, or product efficacy.
- Context remains explicit opt-in and default-off. This release does not enable
  broad runtime injection.

## Verification

The release path verifies the deterministic corpus, candidate identity
rejection, package installation, type safety, documentation, scope, protected
CI, canonical tar identity, and registry provenance before recording a stable
publication.
