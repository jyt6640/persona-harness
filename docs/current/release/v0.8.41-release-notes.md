# v0.8.41 Release Notes

## Clearer Local Integration Diagnostics

This release makes the local Persona Harness state easier to inspect when a
project has an incomplete setup or when OpenCode has not exposed native skill
delivery evidence.

- `ph philosophy status` now reports a sanitized project-convention summary:
  profile readiness, convention state, the local philosophy-injection setting,
  and an explicitly unobserved host-delivery field. It does not print the
  convention text or create personal state.
- `ph workflow diagnose` provides a read-only classification of workspace
  intake, active workflow files, historical archives, and the source-read
  prerequisite. `ph attach --repair --yes` points to that diagnosis rather than
  asking the user to repeat the same repair after an intake failure.
- Packaged shared skills now expose short native-skill descriptions, and
  `ph doctor` distinguishes a locally valid catalog and configured advisory
  route from adapter reachability, host selection, and host delivery that have
  not been observed.

## Safety And Scope Boundaries

- Project philosophy and Context behavior remain explicit opt-in and default
  off; this release does not enable runtime injection by default.
- Diagnostics are read-only and fail closed for malformed, unsafe, foreign, or
  incomplete state. They do not repair a workspace, rewrite history, or grant
  Finish authority.
- Catalog metadata does not claim that a host selected a skill, loaded its full
  body, or delivered it to a session.
- This release does not invoke workflow, shell/process execution, network,
  GitHub, evidence, authority, credentials, fixture, or external-observation
  behavior from these diagnostic paths.

## Verification

The release path verifies the focused philosophy, workflow-diagnostic, shared
skill, and doctor reachability regressions; TypeScript type safety; the default
fast regression suite; documentation and release-policy checks; an isolated
installed tarball; protected CI; canonical package identity; and registry
provenance.
