# v0.8.20 Release Notes

## Current package authority

`0.8.20` is the current unpublished package authority. The root package,
lockfile, private shared-skills package, and
`consumer-authority-v0820-acceptance.json` bind the same version. Published
`0.8.19` is immutable historical evidence and cannot authorize this candidate
or a replacement publish.

## Portable baseline repair

`ph attach --repair --yes` now preserves the caller project's canonical
realpath while it verifies staging ownership for a recognized manifest-less
portable static baseline. The final init manifest therefore binds the caller,
not the temporary repair workspace.

The init manifest's package-template digest remains derived from canonical
package templates. Strict bootstrap overlays affect only effective source file
digests, so a repaired baseline can complete the next strict bootstrap and
explicit plan-accept lifecycle without a false package-binding mismatch.

## Release boundary

Fresh Source and Package gates must bind the exact 0.8.20 candidate and its
canonical tar before protected integration, stable Release, and a single npm
`latest` publication. Fixture and V4 observations remain separately governed.
