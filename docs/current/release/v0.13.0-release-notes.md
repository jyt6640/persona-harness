# v0.13.0 Release Notes

## Portable Socratic Interview Core

Persona Harness now ships a host-neutral, default-off Socratic product-discovery
core. The canonical `deep-interview` skill can reference the same bounded state
machine from the generated Codex, Claude Code, OpenCode, and Antigravity adapter
representations without depending on an OpenCode runtime session.

An explicit CLI boundary starts or inspects the portable interaction:

```bash
npx ph interview start --json
```

It presents a visible activation state, asks one plain-language question at a
time, reports progress in ten-percent steps, keeps a clarification on the same
question, and requires approval before a technical handoff.

## Decision Privacy And Safety

The active JSON state is transient and caller-local. On explicit approval, the
only project write is `.persona/decisions/socratic-interview.json`, a structured
record of approved decisions suitable for Git. It does not store session IDs,
prompts, raw conversation transcripts, host metadata, workflow state, or
implementation instructions.

Malformed, stale, foreign, symlinked, and version-mismatched state is rejected
before a follow-up question or a project write. Cancelling an interview writes
nothing and does not permit an implicit restart.

## Compatibility

- The existing OpenCode product-interview tracker now renders the shared core
  while retaining its host-specific selection and suppression behavior.
- `runtimeInjection` remains default-off, and this release does not alter host
  configuration or claim live host-session delivery.
- The CLI does not invoke workflow, shell, network, GitHub, evidence, or
  authority surfaces.

## Verification

Source and installed-package checks cover portable state transitions, visible
activation, explanation-before-advance, approval, cancellation, decision-record
replay, and unsafe-state rejection. Generated host adapter files are byte-bound
to the canonical skill guidance. Registry and provenance readback remain part of
the governed release workflow.
